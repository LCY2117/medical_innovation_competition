# 盲审安全与证据材料检查清单

更新时间：2026-05-26

适用范围：第十二届全国大学生医学创新大赛国赛网页端材料提交、PPT 盲审、现场答辩前自查。本文用于团队内部检查，防止把未完成事项写成既成成果。

项目定位：本科组、实验设计类、交叉学科、AI 创新设计。当前主展示为 Web 总控台、`/mobile` 四端协同、系统级模拟预实验和证据包导出。

## 1. 盲审安全总原则

- 所有材料必须使用模拟数据、脱敏数据或明确标注的样例数据。
- 不出现真实患者姓名、电话、身份证号、精确住址、病历号、照片或可识别影像。
- 不宣称临床疗效，不宣称提升抢救成功率，不写成真实急救系统已经落地应用。
- 不把系统级模拟预实验写成真人实验、临床试验或真实急救验证。
- 不伪造专家签字、伦理批件、医院合作、真实 AED 点位核验或外部测试结论。
- 未完成的团队/外部事项必须写为“待完成”“计划中”“需复核”，不能写为“已完成”。

## 2. 盲审材料匿名化检查

| 检查项 | 要求 | 状态 |
| --- | --- | --- |
| 团队身份 | 按赛事要求决定是否隐藏学校、导师、成员姓名 | 待团队确认 |
| 文件元数据 | PDF、PPT、Word、图片中不泄露作者账号或本机路径 | 待检查 |
| 截图数据 | 页面截图中不出现真实个人信息 | 待检查 |
| 代码仓库链接 | 如盲审要求匿名，不放实名 GitHub / Gitee 链接 | 待团队确认 |
| 致谢页 | 盲审版本不出现可识别导师、医院或机构信息，除非赛事允许 | 待团队确认 |
| 二维码 | 二维码指向匿名演示入口或公开允许访问页面 | 待检查 |

建议操作：

- 导出 PDF 后查看文档属性，删除作者、公司、修订记录等隐含信息。
- 对网页截图进行放大检查，确认右上角账号、调试路径、数据库 id 不泄露敏感信息。
- 如果需要同时准备盲审版和答辩版，文件名明确区分：`blind_review` 与 `defense`。

## 3. 医学安全与合规口径检查

| 检查项 | 合格表述 | 禁止表述 |
| --- | --- | --- |
| 项目性质 | 急救协同训练与实验设计原型 | 临床急救产品、诊疗系统 |
| AI 作用 | AI/规则辅助角色分派和流程记录 | AI 自动诊断、AI 决定治疗 |
| 预实验 | 系统级模拟预实验、桌面推演 | 真人临床验证、真实抢救实验 |
| 结果结论 | 验证工程闭环和数据记录能力 | 提升抢救成功率、改善预后 |
| AED 数据 | 样例点位、待人工核验点位、已核验点位 | 保证真实可用、全量覆盖 |
| CPR / AED 提示 | 训练流程提示，需遵循专业规范和设备说明 | 替代专业医护判断 |

PPT 和答辩中必须至少出现一次明确边界：

> 本项目当前为急救协同训练和实验设计原型，已完成系统级模拟预实验，不宣称临床疗效，不替代 120、专业医护或 AED 设备说明。

## 4. 证据包检查清单

证据包用于支撑“系统可记录、可复盘、可导出”，不是临床疗效证明。

| 模块 | 必备内容 | 检查标准 |
| --- | --- | --- |
| 事件摘要 | 事件 id、模拟场景、开始/结束时间、状态 | 字段完整，标注为模拟事件 |
| 角色记录 | 患者端、核心施救端、AED 保障端、环境清障端 | 至少覆盖四端角色 |
| 时间线 | 触发、分派、接单、到场、AED 节点、归档 | 节点顺序合理，无空白关键字段 |
| 调度解释 | 角色分派原因、任务优先级、规则/AI 输入 | 能解释为什么这样分派 |
| 操作日志 | 端侧操作、状态变化、异常等待 | 能支持复盘，不含敏感个人信息 |
| 导出信息 | 导出时间、文件名、导出人或测试者代号 | 文件可追溯但不实名泄露 |
| 局限性 | 模拟环境、非临床、非真人或低风险场景预实验状态 | 不夸大结论 |

证据包命名建议：

| 类型 | 建议命名 |
| --- | --- |
| 单轮模拟证据包 | `lifereflex_evidence_round_01_YYYYMMDD.zip` |
| 汇总表 | `lifereflex_pre_experiment_summary_YYYYMMDD.xlsx` |
| 截图包 | `lifereflex_beta_screenshots_YYYYMMDD.zip` |
| 录屏 | `lifereflex_web_beta_5min_YYYYMMDD.mp4` |

## 5. 系统级模拟预实验记录检查

| 检查项 | 要求 | 状态 |
| --- | --- | --- |
| 实验目的 | 写明验证多端协同、时间线记录、证据包导出 | 待填写 |
| 实验环境 | 浏览器、电脑、部署入口或本地环境、测试日期 | 待填写 |
| 参与方式 | 说明同一测试者模拟多角色，或多人低风险场景预实验 | 待填写 |
| 轮次记录 | 每轮起止时间、是否完整闭环、失败原因 | 待填写 |
| 指标记录 | 完整闭环轮次、导出成功次数、关键节点完整性 | 待填写 |
| 问题记录 | 同步延迟、页面误触、字段缺失、导出异常 | 待填写 |
| 修复记录 | 已修复、未修复、赛后优化事项分开写 | 待填写 |
| 局限性 | 明确不能代表真实急救压力和临床效果 | 必填 |

推荐结论模板：

> 本轮系统级模拟预实验初步验证了 Web 总控台、`/mobile` 四端协同、时间线记录和证据包导出的工程闭环。由于实验仍处于桌面推演或低风险场景预实验阶段，结果不能推断临床疗效，也不能代表真实急救场景中的多人操作压力。后续需在医学专家指导下补充真人低风险场景预实验、可用性问卷和专家复核。

## 6. PPT 截图与页面证据检查

| 截图 | 必须展示 | 注意事项 |
| --- | --- | --- |
| 总控台首页 | 事件状态、角色概览、关键入口 | 不出现真实账号或后台路径 |
| 四端 `/mobile` | 患者端、施救端、AED 端、清障端 | 每端标题清晰，能看出同一事件 |
| 调度解释 | AI/规则输入、分派原因、任务建议 | 不写成自动诊疗结论 |
| 时间线 | T1-T6 或同类关键节点 | 标注为模拟演示数据 |
| 证据包导出 | 导出按钮、导出结果或字段结构 | 导出失败不得伪造成成功 |
| 预实验记录 | 轮次、完整闭环、问题和修复 | 不把计划中数据写成已完成 |

截图质量要求：

- 截图分辨率满足 PPT 放映，不模糊、不裁掉关键字段。
- 页面时间、角色和事件 id 前后一致。
- 颜色、字体和图标不遮挡正文，不把调试信息放进最终 PPT。
- 如使用拼图，四端排列顺序固定为：患者端、核心施救端、AED 保障端、环境清障端。

## 7. 专家反馈前检查

专家反馈必须真实发生后才能写入“已完成”。反馈前只能写为计划、提纲或待办。

### 7.1 可提前准备

- 专家反馈邀请函或说明文案。
- 10 分钟演示链接、5 分钟录屏和 PPT。
- 专家评审表：医学安全、流程合理性、训练价值、风险边界、改进建议。
- 需专家重点确认的问题清单。

### 7.2 不得提前写成成果

- 不写“已获得急诊专家认可”，除非已有真实记录。
- 不写“专家一致认为可用于临床”，即使专家口头肯定也不建议这样表达。
- 不伪造专家签名、单位、职称或反馈日期。
- 不用未授权的医院/机构名称作为合作背书。

### 7.3 专家反馈记录字段

| 字段 | 说明 |
| --- | --- |
| 专家代号 | 盲审材料中可用 E01、E02 |
| 专业背景 | 急诊、护理、公共卫生、医学教育等 |
| 反馈日期 | 真实日期 |
| 观看材料 | PPT、网页演示、录屏、证据包 |
| 正向意见 | 与系统定位相关的具体意见 |
| 风险提醒 | 医学安全、误用风险、表述边界 |
| 修改建议 | 可执行的页面、流程或材料修改 |
| 采纳状态 | 已采纳、部分采纳、暂未采纳及理由 |

## 8. 团队待办与外部待办

以下事项是待办，不得在 PPT、摘要或答辩中伪造成果。

### 8.1 团队内部待办

| 事项 | 负责人 | 输出物 | 状态 |
| --- | --- | --- | --- |
| 录制 5 分钟网页端演示视频 | 待分配 | `lifereflex_web_beta_5min_YYYYMMDD.mp4` | 待完成 |
| 截取总控台和四端页面图 | 待分配 | 6 张以上 PPT 截图 | 待完成 |
| 跑 3-5 轮系统级模拟预实验 | 待分配 | 预实验记录表和证据包 | 待完成 |
| 整理导出证据包 | 待分配 | zip / xlsx / 截图包 | 待完成 |
| 检查盲审 PDF 元数据 | 待分配 | 匿名化 PDF | 待完成 |
| 统一 PPT 安全表述 | 待分配 | 最终答辩 PPT | 待完成 |

### 8.2 外部依赖待办

| 事项 | 外部对象 | 输出物 | 状态 |
| --- | --- | --- | --- |
| 医学专家反馈 | 急诊/护理/医学教育专家 | 反馈表或访谈纪要 | 待联系 |
| AED 点位人工核验 | 校园管理方或团队实地核验 | 已核验点位表 | 待核验 |
| 真人低风险场景预实验 | 志愿者和指导老师 | 预实验记录、问卷、知情说明 | 赛后或后续阶段 |
| 伦理/管理审批 | 学校或相关管理部门 | 审批意见或备案 | 按实际需要办理 |

## 9. 终稿提交前 15 分钟快检

- PPT 是否删除了“临床验证”“疗效提升”“真实抢救成功”等越界词。
- 摘要是否把预实验写成“系统级模拟预实验”。
- 所有截图是否无真实个人信息、无调试路径、无账号泄露。
- 证据包是否能打开，文件名和内容是否一致。
- 专家反馈是否只写真实完成内容，未完成事项是否列为待办。
- 盲审版是否按赛事规则匿名。
- 答辩口播是否包含“不宣称临床疗效”的安全边界。
- 如现场演示失败，是否有录屏、截图和证据包字段模板作为备份。
